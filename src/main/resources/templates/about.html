О приложении

«Каталог фильмов» — учебное веб-приложение, разработанное в рамках курсового проектирования по дисциплине «Технологии программирования». Приложение позволяет вести каталог фильмов и связанных с ними актёров, рассчитывать прибыль и рентабельность карточки фильма.

Система поддерживает три роли. READ_ONLY назначается при регистрации и даёт доступ только к просмотру. USER может создавать, изменять и удалять собственные записи. ADMIN имеет полный доступ ко всем данным и управляет ролями пользователей.

Используемые технологии

  • Java 17, Spring Boot 4.1.2
  • Spring MVC, Thymeleaf, Spring Security
  • Spring Data JPA, Hibernate, H2 Database
  • Lombok, Bean Validation, Spring Boot Actuator

Возможности

  • аутентификация и регистрация пользователей;
  • списки фильмов и актёров с поиском по доступным записям;
  • формы добавления и редактирования записей;
  • расчёт прибыли и рентабельности фильма;
  • мониторинг через Actuator.
